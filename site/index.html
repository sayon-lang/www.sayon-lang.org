Programming made easy.
Safety made automatic.

Sayon means “easy”. Ordinary programs need fewer decisions, less boilerplate, and less setup, while the compiler checks who owns each value, so memory is freed on time without a garbage collector.

Get started Read the language guide 
function total(values: Array<integer>) -> integer
    result = 0
    for value in values
        result = result + value
    return result

numbers = [1, 2, 3]
print("Sum: {total(numbers)}")
print(length(numbers))  # numbers is still owned here

Reads like what it does

Blocks by indentation, whole words for keywords, and values written into strings where they go. Types are inferred, and you name them where it helps.

Safe without trying

The compiler checks ownership and infers borrowing, so each value is cleaned up exactly once, at a time you can tell from the code. No garbage collector, no hidden copies.

Errors that teach

Every diagnostic has a stable code, points at the problem, and suggests a concrete fix. sayon explain says more about any of them.

One program, many places

Run it in the interpreter, or compile it through LLVM to a native program for Windows or Linux, WebAssembly for WASI and web pages, or an Android app.

Early days

Sayon is in early development and not ready for real programs yet. What exists, what is planned, and for which milestone is in the feature ledger.

Get started

  1. Download the installer for your device from the releases page and run it. Installing lists them all.
  2. Open a new terminal and make a project: 
    sayon init hello
cd hello
sayon run
  3. For VS Code, install the Sayon extension: highlighting, errors as you type, completion, and more.
